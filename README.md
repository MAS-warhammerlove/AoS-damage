# AoS ダメージ期待値計算（非公式）

Warhammer Age of Sigmar の攻撃で、相手に**平均何ダメージ入るか**と、**何ダメージ以上入る確率**を計算するツールです。

👉 **使ってみる：https://mas-warhammerlove.github.io/aos-damage/**

スマホ・PCのブラウザで動き、インストールやログインは不要です。一度開けばオフラインでも使えます。

---

## 基本の使い方

1. **防御側**のセーヴと加護（ワード）を選ぶ
2. **武器**の攻撃回数・ヒット・ウーンズ・貫通・ダメージを入力する
3. 画面下に**期待値**と**ダメージの確率**がすぐ表示される

数値を変えるたびに自動で再計算されます。

## 入力項目

| 項目 | 説明 |
|---|---|
| モデル数 | その武器を持っているモデルの数。攻撃回数に掛け算されます |
| 攻撃回数 | 1〜10、D3、2D3、D6 などから選択。リストにない値は「手入力…」で `2D6+1` のように入力 |
| ヒット / ウーンズ | 必要な出目（3+ なら 3 を選択） |
| 貫通 | 相手のセーヴを悪くする値（−1 なら 1） |
| ダメージ | 1〜6、D3、D6 などから選択。手入力も可 |
| セーヴ | 防御側の防御力 |
| 加護（ワード） | ダメージ1点ごとに判定して打ち消す能力 |
| セーヴ修正 | 遮蔽などで +1、デバフで −1 |

### 修正・振り直し・クリティカル（各武器の「▸」を開く）

- **ヒット修正 / ウーンズ修正**：アビリティによる ±1
- **振り直し**：「1を振り直し」または「失敗を振り直し」
- **クリティカル**（無修正の6）
  - **2 Hits**：1回のヒットが2ヒットになる
  - **Auto-wound**：ウーンズロールなしで自動成功
  - **Mortal**：ウーンズとセーヴを飛ばして致命傷ダメージ

武器が複数あるキャラは「＋ 武器プロファイルを追加」で増やせます。合計の期待値が表示されます。

## キャラの保存と呼び出し

- **保存**：武器を入力してキャラ名を入れ「保存」。同じ名前なら上書き
- **呼び出し**：「保存済みキャラを呼び出す」から選ぶと武器が丸ごと入れ替わる
- **新規**：「新規（クリア）」で入力欄を空にする
- **削除**：呼び出した状態で「削除」を2回押す

保存時に「このキャラの防御力・加護」も記録しておくと、**防御側の「保存キャラから選ぶ」**でセーヴと加護を一発でセットできます。

## ダメージの分布

- **期待値**：何度も攻撃したときの平均ダメージ
- **Nダメージ以上の確率**：20,000回のシミュレーション結果。バーが長いほど起こりやすい
- **相手の残りヘルス**を入れると、そのダメージ以上を与える（＝倒しきれる）確率が出ます

## バックアップ

保存したキャラは**お使いのブラウザの中だけ**に保存されます。ブラウザのデータ消去や機種変更で消えるので、大事なデータは控えておきましょう。

1. 「バックアップ」を開いて「書き出し」→「コピー」
2. メモアプリなどに貼り付けて保存
3. 復元するときは貼り付けて「読み込み」

## ホーム画面に追加する

- **Android（Chrome）**：メニュー（︙）→「ホーム画面に追加」または「アプリをインストール」
- **iPhone / iPad（Safari）**：共有ボタン →「ホーム画面に追加」

アイコンから起動すると、アプリのように全画面で使えます。

## 計算のルール

- ヒット／ウーンズは無修正の1で常に失敗、無修正の6で常に成功
- クリティカルは無修正の6（振り直し後の出目）で判定
- セーヴの必要値 ＝ セーヴ値 ＋ 貫通 − セーヴ修正。無修正の1は常に失敗
- Crit (Mortal) は武器のダメージ分の致命傷ダメージ
- 加護はダメージ1点ごとに判定（致命傷にも適用）
- 余ったダメージは次のモデルに持ち越す前提

特殊なアビリティ（条件付きのダメージ増加など）は自動では反映されません。該当する場面では数値を手で調整してください。
